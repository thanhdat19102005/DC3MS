# DC3MS

## 📖 Introduction

Develop a disaster rescue management system that allows citizens to easily send emergency requests for help and enables rescue teams to coordinate and manage response operations efficiently



## Main Features

-  User Authentication & Authorization
-  Online Rescue Request Management
-  Rescue Team Management
-  GPS & Digital Map Integration
-  Real-time Chat & Video Call (SignalR)
-  Emergency SMS Notification
-  AI Chatbot
-  AI Agent (n8n) for Social Media Monitoring
-  Weather Information Integration
-  Dashboard & Statistical Reports
-  Notification & Rescue Request Tracking



## Technologies

### Backend
